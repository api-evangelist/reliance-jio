# Reliance Jio

> Reliance Jio Infocomm is India's largest mobile network operator, serving roughly half
> a billion subscribers on an all-IP 4G/5G network, alongside JioFiber broadband,
> JioAirFiber fixed wireless, IoT connectivity, and the JioCX CPaaS business. Its API
> posture is split: standards-forward but private on the network/BSS side (TM Forum Open
> API Platinum, CAMARA SIM Swap under GSMA Open Gateway, reachable only through Aduna and
> the GSMA federated hub), and genuinely self-serve on the SaaS side (JioMeet and
> JioEvents REST APIs at dev.jiomeet.com). Jio serves no downloadable OpenAPI document
> anywhere; the three specs below were harvested by API Evangelist from the OpenAPI
> objects embedded in Jio's own published documentation build.

Generated 2026-07-25 by the API Evangelist enrichment pipeline. Jio publishes no
/llms.txt of its own (dev.jiomeet.com/llms.txt returns 404).

## APIs

- [JioMeet Platform Server API](https://dev.jiomeet.com/docs/JioMeet%20Platform%20Server%20APIs/jiomeet-platform-apis): Server-to-server meeting provisioning, recording and reporting. Host https://jiomeetpro.jio.com. App-credential JWT (HS256/RS256). 11 operations.
- [JioMeet Platform OAuth API](https://dev.jiomeet.com/docs/JioMeet%20Platform%20OAuth%20APIs/jiomeet-user-oauth-apis): User-authorized scheduled meetings and profile. Host https://jiomeetpro.jio.com. OAuth 2.0 authorization code. 7 operations.
- [JioEvents Platform Server API](https://dev.jiomeet.com/docs/JioEvents%20Platform%20Server%20APIs/jioevents-platform-apis): Webinars, sessions, meeting invites and attendance reporting. Host https://jioevents.com. App-credential JWT. 11 operations.
- [JioPayments Set-Top-Box API](https://developer.jio.com/set-top-box.html): In-app purchase API for Jio set-top-box apps, published only as a PDF specification (v1.1).

## Not published by Jio

- No downloadable OpenAPI, Swagger, AsyncAPI, GraphQL schema or .proto file on any Jio property.
- No webhooks and no event surface (the postMessage contract is in-page only).
- No hosted MCP server, no first-party Postman workspace, no CLI.
- No status page, no SLA, no changelog, no deprecation policy, no public roadmap.
- No first-party GSMA Open Gateway / CAMARA developer portal - opengateway.jio.com does not resolve.
- No developer documentation for JioCX (CPaaS) or Jio IoT - both are sales-led marketing pages.
